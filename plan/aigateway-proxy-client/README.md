## 文档维护规则

- 当前规则直接修改需求或对应设计，避免追加“前文已过期，请看文末”的多代互相覆盖说明。
- 线上验收集中更新 `usd-installation.md`，注明观察时间、证据和未验证项；过期快照不写成“当前”。
- 通用操作只维护 `plan/aigateway-proxy-client/operations.md`，不把本机临时适配器或某次计划变成公共安装命令。
- 只在 `release-history.md` 追加有必要保留的发布节点；一般按钮、文案和布局修订不再新建发布文档。
- 旧版本细节留在 Git 历史，不在本目录另建 archive；凭据、安装包、账本、备份和操作 journal 保留私有。
- 删除文档时同步修复引用；已应用迁移、原始金融证据和恢复材料不属于文档清理范围。
