# AIGateway-Proxy 有效需求

整理日期：2026-10-17。本文件合并已确认修订，不再并列保留互相覆盖的旧版本草案。
实现入口见 [插件设计](design.md)；线上安装状态单独见 [USD 安装与配置](usd-installation.md)。
本文件不表示本次重新测试或部署。

## 1. 双版本与下载权限

- 用户版和订阅版独立安装；供应商、账号、本地状态和授权互不覆盖，不自动把旧插件迁移为另一版。
- 下载页桌面双列、窄屏单列；统一平台字体、按钮、凭据确认及状态样式，移除冗余介绍和订阅版导入说明。
- 标题右侧按操作系统提供官方客户端下载入口，保留其他版本链接；平台用户可见文案使用“客户端”。
- `user-plugin`、`subscription-plugin` 两个下载动作按角色独立配置，服务端和下载入口均校验。
  菜单权限、下载权限、数据范围、应用归属及模型权限分别判断，不能相互替代。
- 用户版还要求本人当月已配置个人预算；未配置提示“暂未开通预算请联系部门管理员”，下载返回 403。
  是否配置与是否还有余额分开，不因预算耗尽撤销下载资格。订阅版不套用个人下载预算门槛。
- 下载前分别确认凭据风险；ZIP/敏感接口 no-store，凭据不进入 URL、日志、普通缓存或 Git。

## 2. 用户版授权与默认订阅

- 当前登录用户下载时取得独立、可撤销的个人授权，安装后自动导入本人账号、默认订阅和模型目录。
  包内含个人 access/refresh 凭据，不含 APIM Key、密码或浏览器 Cookie。
- 有效显式用户绑定优先；否则按平台调用实际网关凭据唯一匹配有效订阅。
  不按名称/归属排序，不固定 cc-switch，也不绕过订阅。
- “刷新模型”沿用当前授权与订阅，完整替换本插件拥有的模型集合；“重新登录”重新验证身份并解析默认订阅。
  订阅失效或默认凭据无法唯一匹配时明确失败，不静默改绑。
- 自动导入不能覆盖已有账号；用户主动退出后不能从旧包自动恢复。重新登录/改名只更新同一稳定用户的槽位。
- 支持平台密码账号和自定义组织；Entra 登录、目录同步与后端服务委托是独立能力，不强制用户迁移到 Entra。
- 真实用户、应用、订阅由服务端确认。会话/轮次/Agent 标签可以来自受限客户端头，但不能作为鉴权依据。

## 3. 订阅版与模型目录

- 订阅版继续选择有权导出的应用订阅、关联 APIM 和主/备用 Key；不创建或轮换密钥，不导出系统订阅。
- 用户版目录由当前人员和应用权限、网关及有效发布共同决定；订阅版仅在下载快照与线上发现交集中更新。
  空授权不得回退成全部模型；实时请求仍执行平台及 APIM 检查。
- 使用平台公开模型 ID 和声明的 Responses、Messages、Chat/Images 协议，不凭模型名称猜协议或替换上游模型。
- 支持流式、取消和原生工具协议，不伪造会话标识、用量或客户端 Agent 图标关联。
- 原生图片登记通过已支持的宿主 CLI，不可用时保留受控图片助手/MCP；不直接改写宿主配置来假装登记成功。

## 4. 名称、归档与品牌

- ZIP 使用用户名或订阅名称，解压根目录等于 ZIP 去除 `.zip`；不以明文内部 UUID 作文件名。
- 模型命名空间使用可读用户名/订阅名和稳定短摘要；账号显示名称，稳定用户 ID 留在内部。
  技术包名可保留摘要，不承诺宿主插件列表一定使用产品显示名。
- 已安装包的 providerId 不因刷新或重新登录变化；更换命名空间需显式替换插件并重新选择 Agent 模型。
- 两版下载复用预生成、符合宿主限制的图标；支持亮/暗主题辨识，不在每次下载时生成。
  预留企业上传后生成/激活图标的服务接口；不宣称企业上传 UI 已交付。

## 5. 额度、趋势与价格

- 用户版只展示本人月度额度，支持 Token/USD 单位；不展示应用共享额度，也不取消应用的实际计量或限制。
- 平台个人预算与人员列表采用一致的整月个人口径；保留历史原始归属、用量、价格和已应用迁移。
- 原生曲线使用宿主真实采样，不补造安装前数据；audit 默认不阻断，用户可显式开启本地阻断。
  平台 block 不可由本地关闭。插件一键控制不是宿主原生滑动开关，不修改宿主用量页面。
- 本地阻断只是提前检查，不能替代跨客户端的服务器准入、预留与结算。未知额度/成本不当成零或无限。
- 下载和目录刷新携带平台实际模型单价，包括输入、输出、缓存读/写及适用价格信息。
  宿主价格导入只管理本插件模型，保留人工价格和其他供应商。
- 同一 APIM 可支持不同组织的 Token/USD 配置，但必须完成兼容执行链路安装。
  页面可选 USD、开关为 true 或测试请求返回 200，都不单独证明金额结算成功。

## 6. 验证和发布边界

- 本地验证包括权限/跨账号隔离、默认订阅、ZIP 内容和路径、价格、额度、图片生命周期及新旧包兼容。
- UI 验证覆盖桌面/手机、主题、多语言、独立风险确认、错误和加载状态；不能把模拟接口测试算作线上配置通过。
- 真实调用需核对订阅、人员归因、正式用量和预算变化；USD 另需预留、完成证据和精确金额结算一致。
- 不修改客户端宿主、其他供应商或日常 Agent 配置；凭据加密尚属独立评估，不宣称已实现。
- 发布前保留可还原材料；共享 Core 改动必须协调相关运行包。金融激活后回退不能恢复旧余额覆盖新消费。
