### 结论与接入范围

定价兼容修复合理，可以在保留当前 main 定制能力的前提下合入：

- 新模型身份变化时清除旧引用、摘要、价格及自动填入的上下文，忽略迟到的旧报价响应。
- 明确暂不计价时发送 null 引用；手工修改上下文后，自动报价不再覆盖用户输入。
- 公网、Azure、Anthropic 来源继续隔离；Decision 不匹配公网聊天价格，图片价格保留明确用途。
- 直接发布按服务端目录重算价格、核对报价摘要与用途，并要求明确确认未计价状态。
- 接受的来源、折扣、列表价和上下文档位随发布持久化；重复激活不覆盖之后的手工修改。
- PostgreSQL 新建连接不再依赖已被迁移 019 删除的名称唯一约束，并同步激活路由绑定。
- 定价合同引用公共 RegistryResponse，避免复制整个注册表及无关模型合同；原 API 安全声明保留。

该分支基于较早的个人功能基线，不能按整文件覆盖 main。历史冲突保留 main 的
数据库目录身份、权限与预算范围、用户设置、客户端插件、Claude/Responses 协议兼容、
图片显式启用和服务端探测授权行为。没有更改迁移 SQL、基础设施、依赖版本或 CI。

### 额外发现并修正

新接受价格的 `price_synced_at` 每次更新，会使同一报价的发布规格摘要变化，
重复请求因此返回“另一个发布正在进行”而不能复用原任务。
新增回归测试先复现该问题，再将这项运行时同步时间排除在不可变发布规格之外。
普通模型价格保存仍更新同步状态；发布激活保留自身的创建时间作为定价同步时间。
修复后，相同报价重复提交返回相同发布 ID 和摘要。
